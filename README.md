## Serpent API

**The affordable SERP & AI-visibility API.** Live search results from Google, Bing, Yahoo, DuckDuckGo and Brave as clean JSON — plus AI-citation tracking (AI Rank) across ChatGPT, Claude, Gemini and Perplexity.

🌐 **[apiserpent.com](https://apiserpent.com)** · 📘 **[Docs](https://apiserpent.com/docs)**

### What you can do

- **Multi-engine search** — organic, news, image, video and shopping results from Google, Bing, Yahoo, DuckDuckGo and Brave, with rich SERP features (AI Overviews, People Also Ask, featured snippets, knowledge panels, local packs).
- **AI Rank** — check whether ChatGPT, Claude, Gemini and Perplexity cite your domain for a keyword, and see which sources those answers pull from.
- **Brand mentions** — track where and how often your brand is referenced across AI engines.
